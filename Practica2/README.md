# Práctica 2. Análisis Exploratorio de Datos (EDA) y preparación de datasets

## Descripción

Este proyecto tiene como objetivo desarrollar un proceso reproducible para diagnosticar la calidad de un conjunto de datos de clasificación, aplicar estrategias de preprocesamiento y evaluar su impacto sobre el desempeño de un modelo predictivo.

## Objetivos

- Comprender el dominio y las características del dataset.
- Identificar valores faltantes, duplicados, inconsistencias y posibles valores atípicos.
- Realizar análisis exploratorio de datos mediante técnicas estadísticas y visualizaciones.
- Comparar estrategias de imputación y tratamiento de valores extremos.
- Analizar el desbalance de clases y aplicar técnicas de tratamiento.
- Evaluar el impacto de las decisiones de preprocesamiento sobre un clasificador.

## Tecnologías

- Python 3.14.0
- Visual Studio Code
- Jupyter Notebook
- Obsidian
- NumPy, pandas, Matplotlib, Seaborn y SciPy
- Scikit-learn e Imbalanced-learn

## Estructura del proyecto

- `datasets/`: archivos de datos utilizados.
- `notebooks/`: código y experimentos reproducibles.
- `imagenes/`: visualizaciones generadas.
- `entregables/`: documentos y presentación.
- `requirements.txt`: dependencias del entorno.
- `Bienvenido.md`: punto de entrada a la documentación en Obsidian.

## Instalación y reproducción

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto en VS Code.
3. Crear un entorno virtual con `python -m venv .venv`.
4. Activar el entorno virtual.
5. Instalar las dependencias con `python -m pip install -r requirements.txt`.
6. Abrir el notebook ubicado en `notebooks/`.
7. Seleccionar el kernel del entorno virtual y ejecutar las celdas en orden.
